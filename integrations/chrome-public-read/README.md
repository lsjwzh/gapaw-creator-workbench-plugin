## 历史实现与验证边界

公开命令 `browser-read-capabilities` 返回独立协议 `multicc-browser-read-v1`，`browser-read` 提供 `status`、`pages`、`read-page`、`inspect-page`、`open-page`。调用者不接触 socket、Cookie、令牌、任意脚本或 CDP。实例配置与监督进程随机编号均参与检查；旧监督进程只能在正常关闭重开后获得接口。

每次页面操作限定明确 HTTPS 来源、实例和目标。正文复用固定 DOMSnapshot 投影，排除表单、密码、隐藏元素与跨源 iframe。URL 输出移除查询和片段。`inspect-page` 在同一实例中打开临时后台副本，观察网站自己发出的请求，按指定路径提取响应 JSON 中明确指定的单值，最后关闭副本，不刷新或关闭原页面。只输出允许的国家代码请求元数据，不输出请求/响应头、请求体或完整 JSON。它不主动调用平台 POST、执行脚本、点击、提交表单或发送消息。

浏览器不判定 Kalodata、TikTok 登录或会员权限。平台域名、已查证的身份接口、错误码及结果判定在达人插件 `src/platform_check.rs`。当前身份接口来自公开网页资源：Kalodata `/user/queryProfile`；TikTok Affiliate `/api/v1/affiliate/account/info_v2`。具体市场、重定向和网站变更仍需真实页面验收。HTTP 200、Cookie 存在或页面标题不作为登录成功证据。

检查总预算有上限；页面太慢、验证码、权限不足或响应结构变化会保留未确认状态。具体指标、时间窗口和会员额度尚未通过此身份探测验证，不把登录通过当作可读取所有筛选字段。对于多个页面，达人工作台要求选择本次使用的页面。

`page-read.2` 修复慢页面触发的通道永久失效：尚未发送的过期请求不改变通道，完整帧边界上的响应超时允许后续查询，迟到回复按请求编号丢弃；半帧、写入失败等仍拒绝复用。页面导航保留关闭临时页的预算。真实独立 Chrome 的七秒延迟页面回归验证了超时后状态仍可查询、原页面保留且临时页关闭。

`page-read.3` 补充半帧超时恢复：已读字节保留在同一管道的有界缓冲区内，下次调用先续读至完整消息边界，再按请求编号丢弃迟到回应。调用方不会收到半份结果。连接中断、错误 JSON、超大响应和写入失败仍禁止复用。公开接口只返回预定义的通道失效、读取超时和响应超限分类，不回显底层错误中的页面内容或凭据。

当时的验证包含 Rust 协议/快照测试和 `verify-public.cjs` 的真实独立 Chrome + 合成 HTTPS 平台。测试构建必须显式开启 `gapaw-read-bridge-test` 且使用新的 `/tmp/cbr-*` 私有目录，未设置测试目录时拒绝运行，不能回退生产身份。历史测试结果不能代替用户指定实例内的真实平台核验。
